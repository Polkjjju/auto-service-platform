# АИС «Автосервис»

## Описание проекта

АИС «Автосервис» — информационная система,
предназначенная для автоматизации основных процессов
работы автомобильного сервисного центра.

Система позволяет управлять клиентами, автомобилями,
заказ-нарядами, ремонтными операциями, запасными частями,
сотрудниками и оплатами.

Особое внимание уделяется микросервису
«Прозрачный ремонт», который позволяет отслеживать
ход выполнения ремонтных работ.

## Основные функциональные разделы

1. Клиенты и автомобили.
2. Заказ-наряды и ремонт.
3. Прозрачный ремонт.
4. Склад и сотрудники.
5. Финансы и отчётность.

## Архитектура проекта

Проект предусматривает два приложения:

- Основное приложение АИС «Автосервис».
- Отдельный микросервис «Прозрачный ремонт».

Приложения будут взаимодействовать через API
и использовать PostgreSQL с разделением ответственности
за хранимые данные.
